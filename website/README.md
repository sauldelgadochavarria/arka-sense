# ArkaSense — sitio web

Landing de producto inspirada en [arkafiscal.com](https://arkafiscal.com): asistencia, nómina y descargas de la app multiplataforma.

## Ver en local

```bash
# desde la carpeta website
npx --yes serve -l 5173
```

Abre http://localhost:5173

## Estructura

- `index.html` — landing
- `contacto.html` — contacto / demo / canales legales
- `contrato.html` — contrato y términos de uso
- `aviso-privacidad.html` — aviso LFPDPPP
- `derechos-arco.html` — ejercicio de derechos ARCO
- `seguridad.html` — directivas de seguridad
- `css/styles.css` · `js/main.js`
- `downloads/` — APK / IPA / EXE / DMG
